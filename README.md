# DocKey Legal Pages

A public, static GitHub Pages website for DocKey’s privacy and support information. The private application source remains in `mkashif130/folio-docs`.

## Before publishing or using in App Store Connect

1. Edit `privacy.html` and `support.html`: provide the responsible operator’s legal identity and a monitored, **private** contact email/form.
2. Verify statements against the release build, server logs and third-party processors. These files are working drafts, not a legal review.
3. In GitHub repository **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
4. Verify live pages at `https://mkashif130.github.io/dockey-legal/privacy.html` and `https://mkashif130.github.io/dockey-legal/support.html`.
5. Only then enter the privacy URL in App Store Connect.

## Publisher information

DocKey is operated by Kashif Butt as an individual developer. No dedicated public DocKey contact email is confirmed yet; do not expose the Apple developer account email or other personal contact details. Add a dedicated monitored private support channel before App Store submission.
